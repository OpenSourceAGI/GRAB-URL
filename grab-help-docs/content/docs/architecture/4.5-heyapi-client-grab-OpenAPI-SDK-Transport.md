The `heyapi-client-grab` package provides a specialized transport layer for SDKs generated by [Hey API](https://heyapi.dev). It replaces the default `fetch` or `axios` clients with `grab()`, allowing generated OpenAPI SDKs to inherit advanced features like automatic retries, frontend caching, rate limiting, request deduplication, and a built-in mock server without changing the generated API surface [packages/heyapi-client-grab/README.md1-15](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/README.md?plain=1#L1-L15)

## System Architecture

The package acts as a bridge between the typed interfaces generated from OpenAPI specifications and the `grab-url` request engine. It implements the `Client` contract required by Hey API while mapping SDK-specific concepts (like security schemes and path placeholders) into `grab()` options [packages/heyapi-client-grab/src/client.ts1-8](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L1-L8)

## Core Implementation

### The createClient Factory

The `createClient` function is the primary entry point. It initializes a configuration state and returns an object containing HTTP method helpers (`get`, `post`, etc.) that all route through a central `request` handler [packages/heyapi-client-grab/src/client.ts112-128](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L112-L128)

Key behaviors of the `request` handler:

- **URL Resolution**: It uses `buildUrl` to resolve path parameters (e.g., `/pets/{petId}`) and append query strings using OpenAPI-compliant serialization [packages/heyapi-client-grab/src/client.ts151-156](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L151-L156)
- **Auth Integration**: It resolves security schemes via `setAuthParams`, supporting `Bearer`, `Basic`, and `apiKey` types [packages/heyapi-client-grab/src/core/auth.ts16-27](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/core/auth.ts#L16-L27)
- **Body Handling**: It removes the `Content-Type` header for empty bodies to prevent incorrect JSON claims [packages/heyapi-client-grab/src/client.ts141-143](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L141-L143)
- **Error Mapping**: It translates `grab()`'s "errors-as-data" philosophy back into the Hey API result format `{ data, error, request, response }`. It checks `supportsRawResponse` to determine if it can use the `onRawResponse` hook for richer error metadata [packages/heyapi-client-grab/src/client.ts78-80](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L78-L80)[packages/heyapi-client-grab/src/client.ts199-235](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L199-L235)

### Key Rewiring Functions

- `generateFromOpenAPI`: Orchestrates the full lifecycle from spec to rewired SDK [packages/heyapi-client-grab/src/generate.ts186-212](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/generate.ts#L186-L212)
- `rewireGeneratedClient`: Scans the output directory. For bundled outputs, it overwrites `client.gen.ts` with a shim that imports `createClient` from `heyapi-client-grab`. For package-based outputs, it performs a string replacement on import statements, changing packages listed in `REPLACED_PACKAGES` (like `@hey-api/client-fetch`) to `heyapi-client-grab`[packages/heyapi-client-grab/src/generate.ts17-25](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/generate.ts#L17-L25)[packages/heyapi-client-grab/src/generate.ts138-173](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/generate.ts#L138-L173)

## Comparison with Standard Clients

Unlike the default `@hey-api/client-fetch`, this transport leverages `grab()`'s internal hooks to provide a more robust developer experience.

| Feature | grab Client Implementation |
| --- | --- |
| **Transport Failures** | Returned as `{ error }` by default, matching `grab`'s behavior [packages/heyapi-client-grab/src/client.ts41-43](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L41-L43) |
| **Body Parsing** | Handled by `grab`'s auto-detection; `getParseAs` infers type from headers [packages/heyapi-client-grab/src/utils.ts79-104](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/utils.ts#L79-L104) |
| **Mocking** | Uses `grab.mock` keys (request paths) to bypass the network [packages/heyapi-client-grab/README.md100-111](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/README.md?plain=1#L100-L111) |
| **Raw Response** | Uses `onRawResponse` (if supported by `grab` version) to extract status and headers [packages/heyapi-client-grab/src/client.ts71-80](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L71-L80) |
| **Empty Responses** | `isEmptyResponse` detects 204/205/304 statuses to return `emptyData()`[packages/heyapi-client-grab/src/client.ts46-68](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/packages/heyapi-client-grab/src/client.ts#L46-L68) |
