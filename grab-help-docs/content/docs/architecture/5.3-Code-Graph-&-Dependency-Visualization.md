The GRAB-URL documentation features an interactive, C4-model inspired dependency graph that provides a visual overview of the monorepo's architecture. It utilizes Mermaid.js for rendering, `svg-toolbelt` for pan/zoom capabilities, and custom TypeScript analysis to map relationships between files, functions, and external packages.

## Interactive Graph Architecture

The visualization system is split between server-side analysis and client-side interactive rendering. It translates the physical file structure and source code imports into a logical graph of components and containers.

## Core Components

### DependencyGraphClient

The `DependencyGraphClient` is the primary orchestrator for the visualization. It manages the state of the graph, including search queries, display options (e.g., showing private functions or NPM imports), and fetching live metadata for external dependencies.

- **NPM Metadata Fetching**: When `showNpmImports` is enabled, the component identifies all unique external packages across the analyzed files and fetches their metadata (description, version) via a batch request to `/api/npm-meta`[docs/components/fumadocs/codegraph/dependency-graph-client.tsx34-98](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-client.tsx#L34-L98).
- **Remote Analysis**: It provides a `handleRemoteLoad` function that triggers the `analyzeRemoteRepository` server action, allowing users to visualize any GitHub repository by URL [docs/components/fumadocs/codegraph/dependency-graph-client.tsx100-112](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-client.tsx#L100-L112).

### buildChart() & C4 Generation

The `buildChart` utility function converts an array of `FileInfo` objects into a Mermaid C4-model string.

- **Container Boundaries**: Files are grouped by their package name (e.g., `grab-api`, `grab-url-cli`) and subdirectories using `Container_Boundary`[docs/components/fumadocs/codegraph/dependency-graph-shared.ts120-173](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-shared.ts#L120-L173).
- **Symbol Nodes**: If enabled in `GraphDisplayOptions`, the function generates specific nodes for private functions, exported functions, and types using `makeSymbolNodeId`[docs/components/fumadocs/codegraph/dependency-graph-shared.ts175-221](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-shared.ts#L175-L221).
- **Styling**: Nodes are color-coded based on their role (entry point, core logic, types, or utility) via the `classifyFile` helper [docs/components/fumadocs/codegraph/dependency-graph-shared.ts69-77](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-shared.ts#L69-L77).

## Interaction Engine

The `MermaidClient` (exported from `Mermaid`) handles the heavy lifting of rendering and binding DOM events to the SVG elements.

### Node Interactions

After Mermaid renders the SVG, `bindInteractions` is called to attach custom behaviors:

1. **Tooltips**: `bindNodeTooltips` attaches `mouseenter` and `mousemove` listeners to `g.node` elements. It surfaces data like file descriptions and exports to the `MermaidTooltipOverlay`[docs/components/fumadocs/codegraph/bind-node-interactions.ts20-61](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/bind-node-interactions.ts#L20-L61).
2. **Search Highlighting**: `highlightMatchingNodes` applies a yellow stroke and bold text to nodes matching the user's search query [docs/components/fumadocs/codegraph/bind-node-interactions.ts68-90](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/bind-node-interactions.ts#L68-L90).
3. **Cross-Linking**: `interceptFiletreeAnchorClicks` captures clicks on links formatted as `#file-path`. Instead of a standard jump, it performs a smooth scroll to the corresponding row in the `FileTreeTable` and applies a temporary highlight [docs/components/fumadocs/codegraph/bind-node-interactions.ts96-114](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/bind-node-interactions.ts#L96-L114).

### Cluster Collapsing

The graph supports collapsing package or directory boundaries. The `toggleCollapse` function (exposed on `window`) recursively hides or shows descendant nodes and edges within a `Container_Boundary`[docs/components/fumadocs/codegraph/dependency-graph-client.tsx125-171](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-client.tsx#L125-L171). It also updates the `➕/➖` icon in the cluster label [docs/components/fumadocs/codegraph/dependency-graph-client.tsx125-137](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/dependency-graph-client.tsx#L125-L137).

### SVG Layout Refinement

To prevent long directory names from being clipped, `widenClusterLabels` adjusts the `width` and `x` attributes of the Mermaid-generated `rect` and `foreignObject` elements for clusters [docs/components/fumadocs/codegraph/pan-zoom-controller.ts18-38](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/codegraph/pan-zoom-controller.ts#L18-L38).

## Server-Side Analysis (`analyzeRemoteRepository`)

The visualization is powered by a server action that performs on-the-fly static analysis of codebases.

1. **Normalization**: GitHub URLs are converted to ZIP archive URLs, attempting both `master` and `main` branches [docs/app/actions.ts56-76](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/actions.ts#L56-L76).
2. **Extraction**: The ZIP is downloaded and extracted into memory using `archiver-web`[docs/app/actions.ts78-81](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/actions.ts#L78-L81).
3. **Inference**: The system attempts to infer file descriptions by parsing leading JSDoc comments or double-slash comments via `inferDescription`[docs/app/actions.ts22-52](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/actions.ts#L22-L52).
4. **Analysis**: Each file is processed by `analyzeFileContent` (from the `code-graph` library) to extract imports, exports, and function signatures [docs/app/actions.ts104-113](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/actions.ts#L104-L113).
