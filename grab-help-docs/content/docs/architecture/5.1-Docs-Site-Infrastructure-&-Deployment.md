This page details the technical architecture of the GRAB-URL documentation portal (`grab.js.org`). The site is built using Next.js and the FumaDocs framework, optimized for deployment on Cloudflare Pages via the OpenNext and Vinext pipelines.

## Next.js & FumaDocs Pipeline

The documentation site leverages Next.js 16 with the App Router. It utilizes `fumadocs-mdx` to manage the content layer, transforming MDX files into a searchable and navigable documentation structure.

### Content Layer & Source Configuration

The content is managed via a centralized source loader that handles page discovery and metadata extraction.

## Deployment & Cloudflare Integration

The site is deployed as a Cloudflare Pages project. Because Next.js is not natively compatible with the Cloudflare Workers runtime, the project uses **OpenNext** and **Vinext** to shim the Next.js build into a format compatible with Cloudflare.

### Deployment Stack

- **OpenNext**: Provides the adapter layer to run Next.js on Cloudflare Workers. Local development uses `initOpenNextCloudflareForDev()`[docs/next.config.ts3-5](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/next.config.ts#L3-L5)
- **Vinext**: A wrapper tool used for building, starting, and deploying the site.
- **Wrangler**: Handles Cloudflare-specific environment types and local development tasks via `wrangler.jsonc`.

## Middleware & Routing Logic

The documentation site uses Next.js middleware and configuration to handle complex routing requirements, such as redirecting MDX requests and managing static assets.

### Rewrites & Image Handling

The `next.config.ts` file defines specific behaviors for the documentation environment:

- **MDX Rewrites**: Requests ending in `.mdx` are redirected to the `llms.mdx` route to facilitate easy content fetching for tools like Claude or Cursor [docs/next.config.ts22-29](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/next.config.ts#L22-L29)
- **Image Optimization**: Next.js image optimization is disabled (`unoptimized: true`) and remote patterns are set for `i.imgur.com`[docs/next.config.ts31-39](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/next.config.ts#L31-L39)
- **External Packages**: The `typescript` and `fumadocs-typescript` packages are marked as `serverExternalPackages` to prevent them from being bundled incorrectly [docs/next.config.ts18](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/next.config.ts#L18-L18)

### Revalidation Strategy

To maximize performance on the edge, LLM routes are configured with `revalidate = false`, meaning they are cached indefinitely until a new deployment occurs [docs/app/llms-full.txt/route.ts8](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/llms-full.txt/route.ts#L8-L8)[docs/app/llms.mdx/docs/[[...slug]]/route.ts:4-4]().
