The GRAB-URL documentation site ([grab.js.org](https://grab.js.org)) is built using Next.js and FumaDocs, featuring a specialized set of UI components designed for high-performance technical documentation and interactive code exploration. The site is deployed as a high-performance documentation portal, utilizing `vinext` for Cloudflare-specific builds [docs/package.json13-15](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/package.json#L13-L15)

## 1. Global CSS Theme (Beige/Sand Desert Paper)

The documentation site implements a custom "Beige/Sand Desert Paper" theme via global CSS variables. This theme provides a high-contrast yet soft reading experience, transitioning from light desert tones to deep slate in dark mode.

### Theme Configuration

The theme is defined in `docs/app/globals.css` using HSL variables for consistent scaling [docs/app/globals.css7-36](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/globals.css#L7-L36)

| Variable | Light Mode (Beige) | Dark Mode (Slate/Sand) |
| --- | --- | --- |
| `--color-fd-background` | `hsl(42, 35%, 97%)` | `hsl(28, 20%, 14%)` |
| `--color-fd-primary` | `hsl(38, 45%, 52%)` | `hsl(38, 45%, 65%)` |
| `--color-fd-border` | `hsl(38, 30%, 82%)` | `hsl(28, 30%, 28%)` |
| `--color-fd-text` | `hsl(28, 30%, 22%)` | `hsl(42, 25%, 88%)` |

**Sources:**[docs/app/globals.css7-36](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/globals.css#L7-L36)

### Glassmorphism & Sidebar

The layout utilizes advanced CSS effects for the sidebar, including `backdrop-filter: blur(20px)` and semi-transparent background colors to create a "Glassmorphism" effect that maintains legibility over animated backgrounds [docs/app/globals.css48-55](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/globals.css#L48-L55) Sidebar elements are forced to stay sticky with `position: sticky` and `height: 100vh`[docs/app/globals.css58-64](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/globals.css#L58-L64)

## 3. Specialized UI Components

### Badge & BadgeTooltip

The `Badge` component in `docs/components/fumadocs/code-tree/badge-tooltip.tsx` is a highly interactive element used to display code entities like Functions, Classes, and Packages [docs/components/fumadocs/code-tree/badge-tooltip.tsx73-93](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L73-L93)

- **ColorizedSignature:** A sub-component that tokenizes TypeScript strings (e.g., `(params: GrabOptions) => Promise<GrabResponse>`) into syntax-highlighted spans using a regex-based tokenizer [docs/components/fumadocs/code-tree/badge-tooltip.tsx25-47](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L25-L47)
- **Pinning Logic:** Users can "pin" a tooltip open via `togglePin` (using `setPinned(true)`) to inspect complex `TypeProperty` lists without losing focus [docs/components/fumadocs/code-tree/badge-tooltip.tsx121-131](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L121-L131) This utilizes `getBoundingClientRect` to clamp the tooltip within the viewport [docs/components/fumadocs/code-tree/badge-tooltip.tsx102-109](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L102-L109)
- **Icon Mapping:** Maps entity types to `lucide-react` icons such as `Package`, `FunctionSquare`, `Braces`, and `Blocks`[docs/components/fumadocs/code-tree/badge-tooltip.tsx49-57](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L49-L57)

## 5. Tooltip & Interaction System

The site utilizes a standardized tooltip system built on Radix UI primitives [docs/components/ui/tooltip.tsx5](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/ui/tooltip.tsx#L5-L5)

- **TooltipProvider:** Wraps components to manage `delayDuration` globally, defaulting to `0` for instant feedback [docs/components/ui/tooltip.tsx9-20](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/ui/tooltip.tsx#L9-L20)
- **TooltipContent:** Implements custom Tailwind animations (`animate-in`, `fade-in-0`, `zoom-in-95`) and utilizes a `TooltipPrimitive.Arrow` styled with the `slate-950` theme color [docs/components/ui/tooltip.tsx39-61](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/ui/tooltip.tsx#L39-L61)
- **Collapsible:** Uses `CollapsiblePrimitive.CollapsibleContent` with custom animations `data-[state=closed]:animate-fd-collapsible-up` and `data-[state=open]:animate-fd-collapsible-down` to handle content visibility [docs/components/ui/collapsible.tsx26-39](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/ui/collapsible.tsx#L26-L39)

### Tokenizer Logic

The `ColorizedSignature` function uses a specific set of keywords and primitives to apply CSS classes from `badge-tooltip.module.css`[docs/components/fumadocs/code-tree/badge-tooltip.tsx25-47](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L25-L47)

| Token Category | Identifiers | CSS Class |
| --- | --- | --- |
| **Keywords** | `=>`, `extends`, `keyof`, `typeof`, `infer`, `readonly`, `new` | `.sigKw` |
| **Primitives** | `string`, `number`, `boolean`, `void`, `any`, `unknown` | `.sigTy` |
| **Parameters** | Word followed by `:` or `?:` | `.sigParam` |
| **Punctuation** | `(`, `)`, `{`, `}`, `...`, `:`, `;`, ` | `, `&`, `<`, `>` |

**Sources:**[docs/components/fumadocs/code-tree/badge-tooltip.tsx12-46](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L12-L46)[docs/components/fumadocs/code-tree/badge-tooltip.module.css227-241](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.module.css#L227-L241)
