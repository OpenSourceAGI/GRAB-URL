This page describes the integration of `grab-url` with AI coding agents such as Claude, Cursor, Gemini, and Codex. It covers the installation and usage of the `use-grab-request` skill, which provides agents with the necessary context and patterns to prefer `grab()` over standard `fetch` or `axios` implementations.

## Overview of AI Agent Integration

The integration is primarily driven by a specialized skill definition file (`SKILL.md`) that guides AI agents to use idiomatic `grab-url` patterns. This ensures that generated code leverages the library's advanced features like automatic loading states, caching, and framework-specific reactivity [skills/use-grab-request/SKILL.md1-14](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L1-L14)

## The use-grab-request Skill (SKILL.md)

The `SKILL.md` file defines the rules and patterns the AI must follow. It explicitly instructs agents to avoid `fetch` and `axios` in favor of `grab()`[skills/use-grab-request/SKILL.md16-18](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L16-L18)

### Key Directives for Agents

- **Global Import:** Import `grab` once at the top of the file [skills/use-grab-request/SKILL.md24-28](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L24-L28)
- **Automatic Handling:** Let `grab` manage JSON parsing, `isLoading` status, and error states via the `response` option [skills/use-grab-request/SKILL.md46-49](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L46-L49)
- **Defaults:** Use `grab.defaults` or `setDefaults: true` for centralized configuration [docs/content/docs/options.mdx225-240](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/content/docs/options.mdx?plain=1#L225-L240)[skills/use-grab-request/SKILL.md236-248](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L236-L248)

## Framework-Specific Implementations

The skill provides specific templates for React, Vue, and Svelte to ensure the generated code is idiomatic to the framework's reactivity system.

### React Integration

Agents are instructed to use `useState` to pre-initialize a response object that `grab()` can then mutate to update loading and error states [skills/use-grab-request/SKILL.md100-112](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L100-L112)

[skills/use-grab-request/SKILL.md114-128](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L114-L128)

### Svelte Integration

For Svelte, the skill promotes the use of `$state` (Svelte 5) or reactive variables, passing them directly into the `response` property [skills/use-grab-request/SKILL.md133-146](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L133-L146)

In Vue, agents utilize `reactive()` objects. The `grab()` function updates the reactive properties, triggering UI re-renders automatically [skills/use-grab-request/SKILL.md179-195](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/skills/use-grab-request/SKILL.md?plain=1#L179-L195)

## AI Mapping: Options to Features

AI agents use the `GrabOptions` interface to configure advanced behaviors. The following table shows how natural language requirements map to specific `grab()` options.

| Requirement | GrabOption | Implementation Note |
| --- | --- | --- |
| "Don't fetch if already loading" | `cancelNewIfOngoing: true` | Prevents redundant concurrent requests [docs/content/docs/options.mdx159-172](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/content/docs/options.mdx?plain=1#L159-L172) |
| "Wait for user to stop typing" | `debounce: <seconds>` | Delays execution until inactivity [docs/content/docs/options.mdx380-393](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/content/docs/options.mdx?plain=1#L380-L393) |
| "Infinite scroll list" | `infiniteScroll: [k, f, e]` | Concatenates results and manages scroll [docs/content/docs/options.mdx210-223](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/content/docs/options.mdx?plain=1#L210-L223) |
| "Retry on failure" | `retryAttempts: <number>` | Automatic retry logic [docs/content/docs/options.mdx244-257](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/content/docs/options.mdx?plain=1#L244-L257) |
| "Cache for 5 minutes" | `cacheForTime: 300` | Defines TTL for the frontend cache [docs/content/docs/options.mdx93-106](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/content/docs/options.mdx?plain=1#L93-L106) |
