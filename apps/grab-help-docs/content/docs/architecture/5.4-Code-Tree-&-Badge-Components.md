The Code-Tree and Badge components provide a rich, interactive visualization of the repository's file structure and internal TypeScript metadata. These components enable users to explore file hierarchies, inspect function signatures, view JSDoc descriptions, and track dependencies without leaving the documentation.

## Overview

The system is built on top of a recursive file scanning engine that extracts static analysis data from source files. This data is then rendered through a series of React components that manage state for filtering, sorting, and interactive tooltips.

### Core Component Hierarchy

1. **`FileTreeView`**: The high-level entry point that handles file scanning and tree generation [docs/components/fumadocs/code-tree/filetree-view.tsx8-40](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-view.tsx#L8-L40)
2. **`FileTreeTable`**: Manages the global state for the view, including search (via Fuse.js), sorting logic, and filter menus [docs/components/fumadocs/code-tree/filetree-table.tsx18-50](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-table.tsx#L18-L50)
3. **`TreeRows` / `FileRow` / `FolderRows`**: Recursive rendering components that display individual nodes and their associated metadata badges [docs/components/fumadocs/code-tree/filetree-rows.tsx1-4](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-rows.tsx#L1-L4)
4. **`Badge` / `NpmBadge`**: Atomic UI units that display metadata (Imports, Exports, Types) and host interactive popovers [docs/components/fumadocs/code-tree/badge-tooltip.tsx73-93](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L73-L93)

## Interactive Badges & Tooltips

The `Badge` component is the primary vehicle for metadata visualization. It supports "pinned" states, allowing users to keep a tooltip open while interacting with other parts of the page [docs/components/fumadocs/code-tree/badge-tooltip.tsx121-131](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L121-L131)

### Syntax Highlighting

The `ColorizedSignature` function provides client-side syntax highlighting for TypeScript signatures. It tokenizes strings using a regex `match` and maps tokens to CSS classes defined in `badge-tooltip.module.css`[docs/components/fumadocs/code-tree/badge-tooltip.tsx25-47](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L25-L47)

| Token Category | CSS Class | Target Pattern |
| --- | --- | --- |
| Keywords | `sigKw` | `=>`, `extends`, `keyof`, `readonly` |
| Types | `sigTy` | `string`, `number`, PascalCase words |
| Parameters | `sigParam` | camelCase words followed by `:` |
| Punctuation | `sigPunc` | `(`, `)`, `[`, `]`, `:`, `,` |

Sources: [docs/components/fumadocs/code-tree/badge-tooltip.tsx12-22](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L12-L22)[docs/components/fumadocs/code-tree/badge-tooltip.module.css227-241](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.module.css#L227-L241)

### Type Property Display

When a badge represents a TypeScript Interface or Type, the tooltip renders a `propList`. This includes the property name, optionality (marked by `?`), the colorized type, and the associated JSDoc description [docs/components/fumadocs/code-tree/badge-tooltip.module.css114-171](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.module.css#L114-L171)

## File Tree Table Logic

The `FileTreeTable` provides advanced data manipulation features, including fuzzy search and multi-column sorting.

### Search Engine

Search is powered by `Fuse.js`. It indexes a flattened array of `SearchRecord` objects created by `buildSearchRecords`[docs/components/fumadocs/code-tree/filetree-utils.tsx156-187](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L156-L187) The engine weights different fields to prioritize exact name matches over description matches [docs/components/fumadocs/code-tree/filetree-table.tsx61-76](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-table.tsx#L61-L76)

### Sorting & Filtering

Users can sort the tree based on the density of metadata (number of imports, types, or exports). The sorting logic is recursive: if a folder is sorted, its children are also sorted according to the same criteria [docs/components/fumadocs/code-tree/filetree-table.tsx125-155](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-table.tsx#L125-L155)

## NPM & Local Import Resolution

The tree visualization distinguishes between external (NPM) and internal (Local) dependencies.

### Local Resolution

The `resolveLocalImport` function attempts to map relative import strings (e.g., `../utils/logger`) to actual file paths within the scanned tree [docs/components/fumadocs/code-tree/filetree-utils.tsx37-60](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L37-L60)

1. It strips file extensions [docs/components/fumadocs/code-tree/filetree-utils.tsx39](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L39-L39)
2. It traverses the directory structure using `..` and `.` logic [docs/components/fumadocs/code-tree/filetree-utils.tsx40-44](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L40-L44)
3. It checks for candidate extensions (`.ts`, `.tsx`, `.js`, etc.) or `index` files [docs/components/fumadocs/code-tree/filetree-utils.tsx49-57](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L49-L57)

### Interactive Linking

If a local import is successfully resolved, the badge becomes a link. Clicking it triggers a smooth scroll to the target file's row in the table (using an ID generated from the path) and applies a temporary highlight effect [docs/components/fumadocs/code-tree/filetree-rows.tsx79-91](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-rows.tsx#L79-L91)

### Tooltip Sections

For local imports, the tooltip displays specific symbols imported from the source file, grouped by category: **Functions**, **Types**, **Classes**, and **Values**[docs/components/fumadocs/code-tree/filetree-utils.tsx95-132](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L95-L132) This is achieved by mapping `localImportSymbols` from the source node's analysis to the `exports` of the target node [docs/components/fumadocs/code-tree/filetree-utils.tsx101-109](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/filetree-utils.tsx#L101-L109)

## Styling and Theme Integration

The components utilize a custom CSS module system (`filetree-table.module.css` and `badge-tooltip.module.css`) to maintain a "Beige & Sand Desert Paper" aesthetic while supporting dark mode [docs/app/globals.css6-36](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/globals.css#L6-L36)

- **Glassmorphism**: Sidebar and popovers use `backdrop-filter: blur()` and semi-transparent backgrounds to create depth [docs/app/globals.css167-177](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/app/globals.css#L167-L177)
- **Responsive Design**: Tooltips automatically clamp their width and position relative to the viewport to prevent overflow on mobile devices [docs/components/fumadocs/code-tree/badge-tooltip.tsx105-108](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.tsx#L105-L108) A dedicated `mobileInfoButton` is displayed on touch devices where hover is unavailable [docs/components/fumadocs/code-tree/badge-tooltip.module.css18-37](https://github.com/vtempest/GRAB-URL/blob/a61acaf0/docs/components/fumadocs/code-tree/badge-tooltip.module.css#L18-L37)
